# T-Shirt World — Free Starter Website

এই ZIP একটি static, mobile-friendly starter website।

## Included
- Home / Products / Custom Design / Offer / Contact
- Cart with browser localStorage
- Custom image upload preview
- Checkout form
- bKash gateway placeholder

## গুরুত্বপূর্ণ
বাস্তব bKash payment চালু করতে backend/server এবং আপনার bKash Merchant Gateway credentials দরকার। Secret/PIN/API key frontend HTML-এ বসাবেন না।

## Free hosting
GitHub Pages / Cloudflare Pages-এর মতো static hosting-এ এই site deploy করা যায়। Custom domain চাইলে domain আলাদা খরচ হতে পারে।
